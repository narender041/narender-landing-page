# Urban Fruit Bowl Stock Management

Static Stock Management Web App.

## Files
- index.html
- styles.css
- app.js
- README.md

## Deployment
1. Upload all files to the ROOT of your GitHub repository.
2. Ensure index.html is directly in the root.
3. Open Vercel.
4. Framework Preset: Other
5. Root Directory: .
6. Build Command: leave empty
7. Output Directory: leave empty
8. Install Command: leave empty
9. Redeploy.

The app uses browser localStorage. No backend or external database is required.

## Optional Logo
If you want to use your original logo, create:
assets/urban-fruit-bowl-logo.png

Then update the header markup in index.html to reference that local file.
