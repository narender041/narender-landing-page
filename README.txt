MASTER EXPENSE MANAGEMENT SYSTEM

READY FOR GITHUB PAGES

Files:
- index.html
- style.css
- script.js

HOW TO USE:
1. Extract the ZIP.
2. Upload all 3 files to the root of a GitHub repository.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch: main and folder: /(root).
6. Save. GitHub will publish the website.

IMPORTANT:
This version is a pure HTML/CSS/JavaScript website with NO Supabase, NO database, NO backend, and no unsupported dependencies.
Expense data is stored in the browser using localStorage.
Use the Export Backup button regularly. You can later Import that backup.

Features:
- Combined dashboard for Urban Fruit Bowl and Western Mylands
- Add, edit and delete expenses
- Company, category and status filters
- Date filters
- Monthly and category analytics
- Company reports
- Print / Save PDF reports
- Custom categories
- Export / import backup
- Responsive mobile design
